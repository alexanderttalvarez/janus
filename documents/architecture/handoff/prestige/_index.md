This program defines Prestige as a committed cross-system authority. It does not reopen Tenant, Progression, Economy, Visitor, or Save ownership.

| Order | Handoff | Status | Scope |

| 01 | [Official Tier Publication](01_official_tier_publication.md) | Approved — 2026-09-05 | Initial official tier, immutable tier/rent policy, snapshot/event contract, and V2 persistence. |

## Program rules

- Implement only approved handoffs in order.
- H1 supplies Tenant H2 and Progression H1 but does not itself calculate Prestige or award Tech points.
- H2 is the only approved MVP calculation: developed-tile Scale × documented Quality minimum 20, committed only through H1. It does not implement the six Quality factors, loan-default behavior, daily trend, or Tech-point awards.
- Any Scale/Quality preview outside H2's H1-committed candidate path remains non-authoritative.
- Any change to an approved handoff requires architecture review and user approval before implementation.
