# Prestige Handoff Index

This program defines Prestige as a committed cross-system authority. It does not reopen Tenant, Progression, Economy, Visitor, or Save ownership.

## Handoffs

| Order | Handoff | Status | Scope |
|---:|---|---|---|
| 01 | [Official Tier Publication](01_official_tier_publication.md) | Draft — ready for architecture approval | Initial official tier, immutable tier/rent policy, snapshot/event contract, and V2 persistence. |

## Program rules

- Implement only approved handoffs in order.
- H1 supplies Tenant H2 and Progression H1 but deliberately does not implement full Prestige calculation or Tech-point awards.
- Any Scale/Quality preview must remain non-authoritative until a later approved calculation handoff.
- Any change to an approved handoff requires architecture review and user approval before implementation.
