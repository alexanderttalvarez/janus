# Amenity Assets

Functional objects placed by the player.

## Trash Can (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Basic amenity. Visual decoration. |
| **Size** | 0.5m × 0.5m × 0.8m |
| **Style** | Low-poly cylindrical or rectangular bin |
| **MVP** | Simple low-poly cylinder or box. Single color. |
| **Post-MVP** | Detailed bin with lid, recycling symbol, material variations. |

## Operations Room (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Staff facility. Base of operations for Cleaners and Security. 2×2 tile footprint. |
| **Footprint** | 4m × 4m (2×2 tiles) |
| **Height** | 4m (full floor) |
| **Cost** | 2,000 Kreds |
| **Capacity** | 2 Cleaners + 2 Security per room |
| **MVP** | Distinctive room visual: different floor color, wall markers, or simple 3D model showing it's a staff room. |
| **Post-MVP** | Detailed interior: desks, equipment lockers, monitors, staff photos. |

### Operations Room Visual Design (MVP)

- Floor: Different color/material from surrounding tiles (e.g., dark blue)
- Walls: Standard walls with a distinctive marker (e.g., "OPS" sign or icon)
- Could be a simple 3D model placed on the 2×2 tile area
