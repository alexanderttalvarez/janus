# Decoration Assets

Non-functional visual objects that enhance the district's appearance and contribute to prestige.

## Planter (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Floor decoration. Boosts visitor experience and prestige. |
| **Size** | 1m × 1m × 0.6m |
| **Style** | Low-poly rectangular or circular planter with plants |
| **Variations** | 2-3 plant types (small bush, tall plant, flowers) |

## Bench (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Seating for visitors. Reduces fatigue. |
| **Size** | 1.5m × 0.5m × 0.5m |
| **Style** | Low-poly bench |
| **Variations** | 2 styles (modern, traditional) |

## Fountain (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Water feature. Prestige boost. |
| **Size** | 2m × 2m × 1m |
| **Style** | Low-poly fountain with water VFX |
| **Variations** | 2-3 fountain styles |

## Sculpture / Art Installation (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Art display. Prestige boost. |
| **Size** | 1-2m tall, 1m base |
| **Style** | Abstract low-poly shapes |
| **Variations** | 5+ unique sculptures |

## Terrace Furniture (Post-MVP)

| Element | Size | Description |
|---------|------|-------------|
| **Outdoor bench** | 1.5m × 0.5m × 0.5m | Seating on terraces |
| **Outdoor planter** | 1m × 1m × 0.6m | Plants on terraces |
| **Outdoor table** | 0.8m × 0.8m × 0.7m | Small tables |

## MVP Approach

Decorations are **not needed for MVP**. The Green Spaces tech node unlocks them post-MVP. For MVP, zone-internal "Decoration" tile typology can be represented by a simple colored floor tile (different from Tenant and Transit tiles).
