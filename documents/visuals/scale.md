# Scale Reference

All measurements in **Godot world units** (1 unit = 1 meter).

## Tile Grid

| Property | Value | Notes |
|----------|-------|-------|
| **Tile size** | 2m × 2m | Square tiles, grid-aligned |
| **Plot size** | 25 × 25 tiles = 50m × 50m | MVP: single plot |
| **Road width** | 6 tiles = 12m | Between plots (post-MVP) |
| **Pedestrian area** | 2 tiles = 4m | Surrounding plot |

## Vertical Scale

| Property | Value | Notes |
|----------|-------|-------|
| **Floor height** | 4m | 2× tile width |
| **Floor plane thickness** | 0.2m | Visual only |
| **Wall height** | 4m | Full floor height |
| **Wall thickness** | 0.15m | Visual only |
| **Door height** | 2.5m | Standard commercial |
| **Door width** | 1.5m | Standard commercial |
| **Maximum floors** | 10 above + 3 below = 14 total | F1–F10, U1–U3 |
| **Floor Y spacing** | 4m per floor | F1 at Y=0, F2 at Y=4, etc. |

## Character Scale

| Property | Value | Notes |
|----------|-------|-------|
| **Visitor height** | 1.7m | ~42% of floor height |
| **Visitor width** | 0.5m | Capsule collision |
| **Staff height** | 1.75m | Slightly taller than visitors |
| **Staff width** | 0.5m | Capsule collision |

## Circulation Elements

| Element | Footprint | Height | Notes |
|---------|-----------|--------|-------|
| **Stairs** | 2×2 tiles (4m × 4m) | 4m | Landing + steps |
| **Elevator shaft** | 1×1 tile (2m × 2m) | Full building height | Vertical shaft |
| **Elevator lobby** | 1×1 tile (2m × 2m) | 4m | Per floor |
| **Elevator cab** | 1.5m × 1.5m | 2.5m | Inside shaft |
| **Escalator** (post-MVP) | 2×1 tiles per direction | 4m | Up + down pair |

## Props & Amenities

| Element | Dimensions | Notes |
|---------|-----------|-------|
| **Trash can** | 0.5m × 0.5m × 0.8m | Small prop |
| **Planter** | 1m × 1m × 0.6m | Floor decoration |
| **Bench** | 1.5m × 0.5m × 0.5m | Seating |
| **Fountain** (post-MVP) | 2m × 2m × 1m | Water feature |
| **Sculpture** (post-MVP) | 1–2m tall | Art installation |

| **Garbage sprite** | 0.3m × 0.3m | Floor decal |

## Zone Interior (MVP)

| Element | Dimensions | Notes |
|---------|-----------|-------|
| **Zone floor overlay** | Per-tile, 2m × 2m | Colored overlay |
| **Business parcel** | Variable rectangles | Generated by AI |
| **Business signage** | 1m × 0.3m | Above entrance |
| **Business door** | 1.5m × 2.5m | Per business |

## Camera

| Property | Value | Notes |
|----------|-------|-------|
| **Projection** | Orthographic | No perspective distortion |
| **Zoom range** | size 5.0–50.0 | 5.0 = close, 50.0 = overview |
| **Rotation** | 90° increments | 4 directions |
| **Angle** | ~45° isometric | Standard isometric view |

## UI Scale

| Element | Size | Notes |
|---------|------|-------|
| **HUD bar** | Full width, ~48px height | Top of screen |
| **Bottom toolbar** | Full width, ~56px height | Bottom of screen |
| **Info panels** | Fixed width ~320px | Stack from right edge |
| **Toast notifications** | ~320px wide | Bottom-right corner |
| **Icons** | 24×24px (base), 32×32px (large) | Consistent grid |
| **Heatmap legend** | ~120px wide | Corner overlay |
