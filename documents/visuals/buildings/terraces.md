# Terrace Assets

## Terrace Tile (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Open-air floor sections. Must be adjacent to non-built space. |
| **Size** | 2m × 2m per tile |
| **Floor material** | Outdoor texture (different from indoor) |
| **Walls** | No perimeter wall on edges facing non-built space |
| **MVP** | Not needed. |
| **Post-MVP** | Different floor material, open sky above, possible railing. |

## Terrace Railing (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Safety barrier on terrace edges. |
| **Height** | 1.1m |
| **Style** | Glass or metal railing |
| **Placement** | On terrace edges facing non-built space |

## Terrace Door (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Manual door placed by player to connect terrace to interior. |
| **Size** | 1.5m × 2.5m (standard door) |
| **Style** | Glass door (outdoor access) |

## MVP Approach

Terraces are **not needed for MVP**. The terrace system is post-MVP. Reserve the visual design space but do not produce assets yet.
