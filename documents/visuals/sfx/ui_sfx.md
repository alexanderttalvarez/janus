# UI Sound Effects

## UI Click (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Feedback for button clicks. |
| **Duration** | ~0.05 seconds |
| **Style** | Short, crisp click sound |
| **MVP** | Single click sample. |
| **Post-MVP** | Slight pitch variation per click for natural feel. |

## UI Confirm (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Feedback for confirmations (Finish Zone, accept tenant, etc.). |
| **Duration** | ~0.1 seconds |
| **Style** | Positive, slightly higher pitch than click |
| **MVP** | Single confirm sample. |

## UI Error (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Feedback for errors (can't place here, insufficient funds, etc.). |
| **Duration** | ~0.15 seconds |
| **Style** | Lower pitch, slightly longer than click |
| **MVP** | Single error sample. |

## UI Hover (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Subtle feedback when hovering over buttons. |
| **Duration** | ~0.03 seconds |
| **Style** | Very soft, barely audible |

## UI Panel Open/Close (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Feedback for panel transitions. |
| **Duration** | ~0.15 seconds |
| **Style** | Soft whoosh or slide sound |

## Reuse Opportunities

- UI click can be reused for all button interactions
- UI confirm and error can be pitch-shifted versions of the same base sample
- All UI sounds should be short and non-intrusive
