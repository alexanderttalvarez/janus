# World Sound Effects

## Zone Place (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Feedback when placing a zone tile. |
| **Duration** | ~0.1 seconds |
| **Style** | Soft thud or placement sound |
| **MVP** | Single placement sample. |

## Zone Delete / Bulldoze (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Feedback when deleting a zone or tile. |
| **Duration** | ~0.15 seconds |
| **Style** | Demolition or removal sound |
| **MVP** | Single delete sample. |

## Construction Start (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Feedback when construction begins on a zone. |
| **Duration** | ~0.2 seconds |
| **Style** | Building/construction sound |
| **MVP** | Single construction start sample. |

## Construction Complete (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Feedback when construction finishes and tenant opens. |
| **Duration** | ~0.3 seconds |
| **Style** | Positive, celebratory sound |
| **MVP** | Single completion sample. |

## Tenant Arrival (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Feedback when a new tenant moves in. |
| **Duration** | ~0.2 seconds |
| **Style** | Positive, welcoming sound |
| **MVP** | Single arrival sample. |

## Crowd Ambience (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Background mall ambience. |
| **Duration** | Looping, 30-60 seconds |
| **Style** | Distant murmuring, footsteps, HVAC hum |
| **Volume** | Low, background level |

## Footsteps (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Footstep sounds for visitors and staff. |
| **Duration** | ~0.1 seconds per step |
| **Style** | Soft footsteps on different surfaces |
| **Variations** | 3-4 variations per surface type |

## Reuse Opportunities

- Zone place and delete can be variations of the same base sample
- Construction sounds can share a construction "kit" (hammer, drill, etc.)
- Crowd ambience is a single looping track
