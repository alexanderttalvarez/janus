# Feedback Sound Effects

## Level Up (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Feedback when reaching a new Mall Level / prestige tier. |
| **Duration** | ~0.5 seconds |
| **Style** | Celebratory, ascending tones |
| **MVP** | Single level-up fanfare. |

## Notification (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Alert sound for toast notifications. |
| **Duration** | ~0.1 seconds |
| **Style** | Soft chime or ping |
| **MVP** | Single notification sample. |
| **Post-MVP** | Different sounds per notification priority. |

## Reuse Opportunities

- Level up sound is a one-off, no reuse needed
- Notification sound can be reused for all toast notifications
- Post-MVP: notification sounds can be pitch-shifted for different priorities
