# UI Icon Set

All icons follow a consistent style: simple, recognizable, 24×24px base size.

## Icon Grid

| Size | Usage |
|------|-------|
| **16×16px** | Small indicators, inline icons |
| **24×24px** | Standard UI icons (HUD, toolbar, panels) |
| **32×32px** | Large icons, build palette buttons |
| **48×48px** | Notification icons |

## Icon Style Guidelines

- **Stroke width**: 2px consistent across all icons
- **Corner radius**: Slightly rounded (2px) for a modern feel
- **Fill**: Solid fill for primary shapes, outline for secondary details
- **Color**: White/light on dark backgrounds, dark on light backgrounds
- **Zone icons**: Use zone-specific accent colors
