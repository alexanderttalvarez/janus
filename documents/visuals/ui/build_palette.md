# Build Palette Assets

The build palette is the bottom toolbar in Build Mode. It contains tool buttons for placing zones, circulation, amenities, and staff facilities.

## Build Mode Tools

| Tool | Icon | Description | Unlock |
|------|------|-------------|--------|
| **Retail Zone** | Shopping bag icon (purple) | Paint Retail zone tiles | Free (start) |
| **Food & Beverage Zone** | Fork/knife icon (green) | Paint F&B zone tiles | Free (start) |
| **Entertainment Zone** | Game controller icon (orange) | Paint Entertainment zone tiles | Advanced Zoning tech |
| **Services Zone** | Wrench icon (blue) | Paint Services zone tiles | Advanced Zoning tech |
| **Anchor Zone** | Building icon (red) | Paint Anchor zone tiles | Anchor Tenants tech |
| **Corridor** | Path/line icon (gray) | Paint corridor tiles | Free (start) |
| **Stairs** | Stairs icon (gray) | Place stairs between floors | Stairs tech |
| **Elevator** | Elevator icon (gray) | Place elevator shaft + lobby | Elevators tech |
| **Escalator** | Escalator icon (gray) | Place escalator pair | Escalators tech (post-MVP) |
| **Operations Room** | Staff room icon (gray) | Place Operations Room (2×2) | Free (start) |
| **Bulldozer** | X or wrecking ball icon (red) | Delete zones, tiles, structures | Free (start) |
| **Amenities** | Plant icon (green) | Place gardens, seating, art | Green Spaces tech (post-MVP) |

## Button States

Each tool button has these visual states:
- **Default**: Normal appearance
- **Hover**: Slightly brighter/highlighted
- **Active/Selected**: Distinct highlight (border glow or background color)
- **Disabled/Locked**: Grayed out with lock icon (for tech-locked tools)

## MVP Approach

For MVP, tool buttons can be simple text labels with colored backgrounds matching the zone colors. Icons can be added post-MVP.
