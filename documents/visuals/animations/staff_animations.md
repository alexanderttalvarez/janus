# Staff Animations

## Staff Idle (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Default animation when staff is stationary. |
| **Duration** | Looping |
| **MVP** | Static pose or subtle breathing. |

## Staff Walk (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Animation when staff is moving to a task or patrol route. |
| **Duration** | Looping, ~0.5 seconds per cycle |
| **Speed** | Matches movement speed (~1.5 m/s) |
| **MVP** | Same as visitor walk (can share animation). |

## Staff Clean (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Animation when cleaner is removing garbage or cleaning bathroom. |
| **Duration** | 1-2 seconds |
| **Actions** | Bend down, pick up garbage, stand up. Or wipe surface motion. |

## Staff Patrol (Post-MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Animation when security is on patrol. |
| **Duration** | Looping walk with occasional stops |
| **Actions** | Walk, stop and look around, continue walking |

## Reuse Opportunities

- Staff walk can share the visitor walk animation
- Staff idle can share the visitor idle animation
- Only cleaning and patrol animations are unique to staff
