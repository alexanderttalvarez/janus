# Ambient Music Tracks

## Main Ambient Loop (MVP)

| Property | Value |
|----------|-------|
| **Purpose** | Background music for the entire game. |
| **Duration** | 2-4 minutes, seamlessly loopable |
| **Genre** | TBD (see style_guide.md open questions) |
| **Mood** | Serene, professional, aspirational |
| **Format** | OGG Vorbis |
| **MVP** | Single looped ambient track. |
| **Post-MVP** | Multiple tracks that change with time-of-day and season. |

### MVP Approach

One ambient track that plays continuously. Should be:
- Non-intrusive (background, not foreground)
- Loopable without noticeable transition
- Calm and pleasant for long play sessions
- No vocals (instrumental only)

## Post-MVP: Time-of-Day Tracks

| Track | Time | Mood |
|-------|------|------|
| **Morning** | 6:00-12:00 | Fresh, optimistic, gentle build |
| **Afternoon** | 12:00-18:00 | Warm, productive, steady |
| **Evening** | 18:00-21:00 | Relaxed, social, winding down |
| **Night** | 21:00-6:00 | Quiet, minimal, ambient |

## Post-MVP: Seasonal Tracks

| Track | Season | Mood |
|-------|--------|------|
| **Spring** | Spring | Light, fresh, blossoming |
| **Summer** | Summer | Warm, energetic, bright |
| **Autumn** | Autumn | Cozy, mellow, golden |
| **Winter** | Winter | Quiet, introspective, cool |

## Music Transitions

- Crossfade between tracks: 5-10 seconds
- No abrupt changes
- Volume can be adjusted independently in settings

## Reuse Opportunities

- All tracks share the same key and tempo for smooth transitions
- Musical motifs can be shared across time-of-day and seasonal variations
